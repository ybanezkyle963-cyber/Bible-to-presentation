Cebuano Bible (YouVersion)

Get a free app key at platform.youversion.com, paste it here, then find a Cebuano Bible and select it.

Free Use Bible API (bible.helloao.org)

No key needed, 1,000+ languages. Type a language code (ceb = Cebuano, tgl = Tagalog, eng = English), then pick a translation. It appears as "Free Use Bible API" in the version list.

wldeh Bible API (GitHub)

No key needed. Type a language code (for example ceb or en), then pick a version. It appears as "wldeh Bible API" in the version list.

Want everything offline? The Free Use Bible API offers full downloads (a zip or a database) on its downloads page.
